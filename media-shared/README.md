# Shared media foundation

Implemented 2026-10-29 against the accepted [async research](../higgsfield/RESEARCH.md), [sync/stream research](../elevenlabs/RESEARCH.md) and the latest HIG-6 owner pricing decision. This is injected consumer code, with two independent neutral adapter fixtures. No vendor adapter, catalog, endpoint, core change, production host route, published package or runnable pipeline is included.

Consumers import relative TypeScript from `src/` using the existing bundler. `MediaCore` in `core.ts` is the actual synchronous production admission/transition/receipt/recovery facade over `contracts.ts` ports and one persisted journal. `MediaController` is an async fixture/UI driver that calls that same core, never a second state machine and never a QuickJS backend export. Distinct async-ticket, direct response and byte-stream fixtures share these decisions. `cost.ts` checks safe fresh exact-operation quotes and accounts independent atomic units. `presentation.ts` holds Iris's shared copy/data primitives; `media.ts` separates free frame reacquisition from availability-gated human actions. No DOM or CSS is included.

## Runtime shape and continuation boundary

Authoritative runtime contract relayed by Concierge and Watt on 2026-10-29, with Loom corroboration at host source `7f7adf9`, `vm.rs::__ct_invoke__/__ct_resume__`: arbitrary thenables are explicitly rejected. `viewCall(method,args,context)` via `call_json` supports only sanctioned explicit `host.awaitJob(jobId,continuation)` / `host.fetch.async(opts,continuation)` yield markers. The export **and nested callback** must return the marker, and callbacks themselves are synchronous. `awaitJob` accepts a sanctioned host job ID, never a provider ID or Promise; it is per-call continuation, not a durable receipt/scheduler. `onSurfaceCall` returns a synchronous string and accepts neither a Promise nor a yield marker. Blueprint callbacks are synchronous plain results with interruptible sanctioned-marker handling, but runner admission remains closed. These are dated source/owner answers, not a released SDK/min-host or live compatibility claim.

Services can import `MediaCore` directly. `intent`, `approve`, `beginEstimate`/`estimated`, `beginStart`/`reserve`/`enter`, `observation`/`complete`, `beginReconcile`, `beginCancel`, `unknown` and `recover` return plain JSON decisions/actions/receipts, not thenables. Exact schema validation and durable atomic storage are synchronous injections. A Promise wrapper around synchronous SQLite is not a valid backend export contract. No generic coroutine, generator runtime, host wrapper, callback registration API or speculative job SDK is implemented here.

The HOST resolves `Access` (owner/workspace/actor/run, current authorization and input grants) before each admission/resume transition, using trusted retained per-call context or fresh ledger-derived authority for a future durable callback. Never reconstruct authority from a revived frame, a client payload, or the local `Continuation` record. The latter is only a persisted intent/binding/epoch correlation value, not a bearer token or host job ID. Each resumed effect revalidates request/binding, quote, approval and relevant authorization. `enter` emits at most one paid action; dispatch it synchronously at that authorized boundary without another await. A repeated entry or stale epoch refuses. External async network/input/authority/media work is wired downstream through the **actual reviewed** host continuation contracts; the common facade does not execute it.

`runtime.test.ts` uses fresh facade instances and JSON-retained continuation correlation across explicit synchronous callback invocations, including the nested return. Its fake host marker is explicitly test-only. It proves plain results, same-intent/same-job receipts, phase/epoch recovery and no submission after expired/revoked preflight; it does not run QuickJS or establish transport/scheduling delivery. Existing independent ticket/direct/stream tests drive this same core through `MediaController`. Binary request/response transport is still text in the cited host; Courier's bounded binary port remains pending. New durable callback registration/names are design-only, and this foundation invents none.

## Injection and authority

The async driver uses `Authority.resolve` for opaque caller fixtures. Production uses HOST-resolved `Access` directly; neither interface licenses arbitrary Promises in a backend VM. Both must establish owner/workspace, actor/run, human authority, sanitized actor label and revocable auth revision. Never implement either by copying request arguments, frame query strings or an agent label. Human scope sees its workspace's jobs; agents see their exact actor/run scope. An owner may approve its agent/run job. Separate workspaces/owners cannot inspect or mutate each other's IDs. Trusted input authorization is required for every nonempty input list. An artifact ID, transient frame handle and durable run media reference are separate types; runtime frame inputs refuse.

`JobStore.transact` must supply **synchronous**, durable atomic transactions serialized across instances/processes, including intents, phases, continuation epochs, leases, ceilings and accounting in one owner/workspace partition; thenable results refuse. The test-only in-memory store is no production persistence. A job binds stable operation ID, revision, exact parameters (including omission/null and array order), input references and exact unit. Same-ID changes refuse. The core's injected validator checks the adapter's exact closed schema before an intent is stored, and the adapter must preserve its documented provider idempotency identity when given the stable intent ID. There is no common vendor schema engine.

The journal is bounded by `maxHistory`. At capacity it refuses new intents rather than evicting identity, unsettled reservations or historical run spend. This is an explicit downstream UX limit: production needs a safe archive/tombstone policy before its bounded feed fills permanently. No speculative archive is implemented here. `recover` is for exclusive post-restart scheduler recovery, never while a live effect owner remains active. Durable scheduling independent of a frame remains an external prerequisite.

Every paid start requires a safe, fresh, exact-unit quote with basis, tariff revision, timestamps and immutable binding, followed by a separate human approval. Unknown/stale/unsafe prices have no override. An estimator is optional and strictly effect-free. Refresh takes a persisted operation lease, changes only quote/approval/wait metadata, and clears prior approval even for a fresh within-budget price. Per-intent ceiling exception does not raise any later intent's ceiling. Integer overflow and unlike units cannot produce an approval. Unknown reservations block the affected run; no automatic paid replay occurs. Run IDs are host-authorized, not user-selected budget buckets.

Submission first persists a `starting` preflight lease without a budget reservation. After external input authorization, `reserve` atomically rechecks immutable intent, price, approval and ceiling; `enter` synchronously revalidates fresh HOST authority and price at paid entry. Persisted phases distinguish `preflight`, `reserved`, `submitting` and `receipt`. Known pre-entry expiry/input refusal/stale authority returns to waiting/refusal without a paid reservation; a restart of the preflight lease is known non-entry and fences its old callback epoch. Once the durable reservation is committed, restart uncertainty remains conservative; once `enter` emits a submission, uncertainty becomes `unknown` and its hold cannot be cleared as preflight refusal. Async receipts persist a write-once job ID and receipt header before external output acquisition; reconciliation only inspects that identity. Sync responses and stream EOF remain distinct: the async fixture driver preserves raw byte order, requires an explicit stream completion event and EOF, and reports a result only after the confined output store finishes and core `complete` accepts saved artifacts. Actual host binary/session transport is external. Sync/stream success retains the conservative quoted reservation because it is not a provider billing receipt. Exact async billing evidence settles to spent, including a confirmed zero/refund; cancellation requests and disconnects never infer a refund. Provider charged amounts can exceed a prior estimate and must be accounted honestly, with the next operation stopped by its ceiling.

`OutputStore.save` must enforce owner/workspace/run artifact authority, MIME/signature, byte/file bounds, confinement and durable saved output. Its artifact path is backend-only. The common in-memory byte assembly is bounded by `maxOutputBytes`; it proves byte correctness for bounded direct/chunked responses, not a delivered large-file or WebSocket transport. Partial output on an uncertain stream is not presented as a saved result. The adapter owns provider-specific session/commit/partial transcript semantics; no generic WebSocket job machine is invented.

`MediaPorts` are UI-only injection seams, not SDK signatures. `acquire` is free; the host authorizes an already-produced artifact in the current document. The adapter derives local `expiresAt` from acquisition time plus the returned TTL. A frame handle never enters job history or pipeline outputs. The consumer observes only mounted state, declaration, actual availability and local handle expiry. It does not receive a frame identity or observe focus/gesture authority. Call `humanAction` from the real click handler; host alone enforces human authority, shown/focused activation, exact-frame ownership, limits and bounded export leases. Host results pass through unchanged as `{ok:false,code:denied|unavailable|invalid,reason:specific}`; `refusalCopy` selects sanitized copy by reason. Agents/pipelines consume backend artifacts/paths through downstream adapters, never this UI gesture helper. Busy/stale effects do not auto-retry. A missing saved file must be separately proven by the backend; an expired frame token never triggers paid regeneration.
