Consumers import relative TypeScript from `src/` using the existing bundler. `MediaController` uses `contracts.ts` ports and one persisted journal for distinct async, sync and stream adapters. `cost.ts` checks safe fresh exact-operation quotes and accounts independent atomic units. `presentation.ts` holds Iris's shared copy/data primitives; `media.ts` separates free frame reacquisition from availability-gated human actions. ## Injection and authority

`Authority.resolve` accepts an opaque caller only through a trusted host integration; it must establish owner/workspace, actor/run, human authority, sanitized actor label and revocable auth revision. Never implement it by copying request arguments, frame query strings or an agent label. Human scope sees its workspace's jobs; agents see their exact actor/run scope. An owner may approve its agent/run job. Separate workspaces/owners cannot inspect or mutate each other's IDs. Trusted input authorization is required for every nonempty input list. An artifact ID, transient frame handle and durable run media reference are separate types; runtime frame inputs refuse.

`JobStore.transact` must supply durable atomic transactions serialized across instances/processes, including intents, leases, ceilings and accounting in one owner/workspace partition. The test-only in-memory store is no production persistence. A job binds stable operation ID, revision, exact parameters (including omission/null and array order), input references and exact unit. Same-ID changes refuse. The adapter must validate its exact closed schema before an intent is stored, and must preserve its documented provider idempotency identity when given the stable intent ID. There is no common vendor schema engine.

The journal is bounded by `maxHistory`. At capacity it refuses new intents rather than evicting identity, unsettled reservations or historical run spend. Capacity reclamation needs a future proven host archive/tombstone policy; this foundation does not silently forget paid identities. `recover` is for exclusive post-restart scheduler recovery, never while a live effect owner remains active. Durable scheduling independent of a frame remains an external prerequisite.

Every paid start requires a safe, fresh, exact-unit quote with basis, tariff revision, timestamps and immutable binding, followed by a separate human approval. Unknown/stale/unsafe prices have no override. An estimator is optional and strictly effect-free. Refresh takes a persisted operation lease, changes only quote/approval/wait metadata, and clears prior approval even for a fresh within-budget price. Per-intent ceiling exception does not raise any later intent's ceiling. Integer overflow and unlike units cannot produce an approval. Unknown reservations block the affected run; no automatic paid replay occurs. Run IDs are host-authorized, not user-selected budget buckets.

Submission persists reservation and `starting` before invoking an adapter. A restart or uncertain transport becomes `unknown`. Async receipts persist a write-once job ID before saving outputs; reconciliation only inspects that identity. Sync responses and stream EOF remain distinct: raw byte order is preserved, a stream requires an explicit completion event and EOF, and successful output requires the injected confined output store to finish. Sync/stream success retains the conservative quoted reservation because it is not a provider billing receipt. Exact async billing evidence settles to spent, including a confirmed zero/refund; cancellation requests and disconnects never infer a refund. Provider charged amounts can exceed a prior estimate and must be accounted honestly, with the next operation stopped by its ceiling.

`OutputStore.save` must enforce owner/workspace/run artifact authority, MIME/signature, byte/file bounds, confinement and durable saved output. Its artifact path is backend-only. The common in-memory byte assembly is bounded by `maxOutputBytes`; it proves byte correctness for bounded direct/chunked responses, not a delivered large-file or WebSocket transport. Partial output on an uncertain stream is not presented as a saved result. The adapter owns provider-specific session/commit/partial transcript semantics; no generic WebSocket job machine is invented.

`MediaPorts` are UI-only injection seams, not SDK signatures. `acquire` is free; the host authorizes an already-produced artifact in the current document. The adapter derives local `expiresAt` from acquisition time plus the returned TTL. A frame handle never enters job history or pipeline outputs. The consumer observes only mounted state, declaration, actual availability and local handle expiry. It does not receive a frame identity or observe focus/gesture authority. Call `humanAction` from the real click handler; host alone enforces human authority, shown/focused activation, exact-frame ownership, limits and bounded export leases. Host results pass through unchanged as `{ok:false,code:denied|unavailable|invalid,reason:specific}`; `refusalCopy` selects sanitized copy by reason. Agents/pipelines consume backend artifacts/paths through downstream adapters, never this UI gesture helper. Busy/stale effects do not auto-retry. A missing saved file must be separately proven by the backend; an expired frame token never triggers paid regeneration.
