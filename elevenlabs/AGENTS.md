# ElevenLabs source adapters

This is a source candidate over the accepted `ElevenLabsService` and synchronous `MediaCore`, not an installable or runtime-ready studio. Final bundles, UI and minimum host declaration belong to HIG-11. Version 0.1.0 is a target. No minimum host or released SDK containing all required capabilities has been proved. No UI changes or Iris approval are claimed.

Discover `help`, `catalog`, `capabilities`, `models` and `describe`. Commands accept one structured JSON body through the agent command body/stdin contract; argv parameters are refused. `describe` takes `{ "operation": "text_to_speech_full" }`. Each finite catalog operation retains primary source/date, exact schema/defaults/limits, availability, account restrictions, transport, cost and lifecycle. `coverage.json` references those complete research rows with deterministic hashes rather than duplicating megabytes of prose. A described operation is not necessarily executable. Display-only model names never become guessed API IDs.

`onAgentCommand` calls the real generic `host.surface.call(verb,argsJson)` path. Host dispatch must create/reuse the authenticated caller's own child view and stamp its context. The adapter never invents tab IDs. `open` and `close` have no plugin-side substitute. The source manifest declares a view, `agentBound`, finite `agentVerbs` and `stateInvalidation`. It has no placeholder UI. Until the following studio task supplies its UI and HIG-11 supplies delivered host wiring, this candidate cannot render a usable studio. The default `onSurfaceCall` and `viewCall` refuse secure-service binding; injected factories are deterministic integration seams, not runtime delivery proof.

`createCommands(service,ports)` consumes the SAME accepted service. `ports.caller` must freshly resolve host identity, workspace and input grants; default/unconfigured ports refuse. Agent owner and actor remain distinct; cross-owner calls are refused without a generic delegation contract. An explicit user document resolver must verify `origin=document`, plugin, frame, workspace and user workspace policy. A `local` actor never establishes human consent. Ordinary input cannot select owner, actor, frame, run or budget. Host-owned intent allocation is required. Live exact-instance invalidation follows successful prepare/rerun/estimate once, without raw activity payloads. HIG-11 must prove real two-agent isolation, sidebar nesting and no-refresh view updates; mocks prove only source wiring.

`prepare` takes `{ "operation":"text_to_speech_full", "params":{"path":{"voice_id":"owned-voice-id"},"body":{"text":"Hello","model_id":"eleven_multilingual_v2"}},"inputs":[],"unit":"usd_micro" }`. It validates and persists one new intent without submission. `rerun` with `{ "id":"authorized-intent" }` prepares a new intent from the same validated request. It never generates. `history`, `activity`, `status`, `inspect`, `result`, `estimate` and `usage` use the same authorized service. Activity excludes prompts, raw arguments, backend paths, errors and secrets. `result` returns authorized opaque artifacts, not frame authority or a vendor URL. `read` validates through `prepareRead`, then refuses absent transport. `generate` deliberately refuses before entry until a real durable host continuation integration is delivered. No approval command is exposed. Cancel/reconcile report exact service limitations; neither pretends to cancel a synchronous effect or replay Unknown. Existing voices/settings and Scribe selection remain untouched.

The manifest declares 15 operation families and one scalar TTS node. Family `operation` enums are discovery declarations only. Current flat NodeSchema cannot encode the API's nested objects, unions, files and per-operation response protocols. Every row explicitly records that limitation; no opaque JSON parameter or converter provides an escape. `elevenlabs.tts` has bounded voice/text/model fields and an audio output contract; `speechRequest()` compiles them into the original service schema without coercion. `createBlueprint` obtains caller and stable intent identity only from injected trusted run ports. It never calls `start`, invents a scheduler, applies a ceiling exception or treats stepAllowance as approval. Submit/reconcile/cancel refuse before paid entry. Cost binding, exact units, fresh account quote and independent owner confirmation remain service/core decisions. There is no pipeline price-refresh UI here.

`blueprints/fixture-zero-spend.yaml` describes source-only synthetic media handoff and bounded review. It is explicitly NOT executable host YAML. A fake handle, text filename or fixture reviewer result cannot satisfy actual media-aware review acceptance. `fixture-production.yaml` records the unavailable runtime contract and cannot be applied. Agent media review needs Loom/Courier's authorized durable run media and actual reviewer modality contract, or Elgar disposition. Frame media handles are ephemeral and never used as durable run references. Run link and one-hop lineage must come from authenticated host run context; no input-supplied URL becomes authority.

When a future delivered host returns an authorized saved image path, report it with existing `@ds-image ABSOLUTE_PATH` or the chosen report attachment mechanism. Never print a backend artifact path merely because a record contains one. No current adapter fabricates a saved path or claims attachment delivery. Audio/video need real playback/export; status alone is insufficient.
