# Catalog service

The service in `src/client.ts` consumes the accepted 2026-10-29 public snapshot in `RESEARCH.md`, `contracts.json`, `capabilities.json`, `models.json` and `evidence/openapi.json`. `catalog()` retains all 466 operation rows, their dated primary sources, schema pointers, prerequisites and explicit limitations. `modelCatalog()` retains all 166 selectors, 81 display-only records and unresolved account catalogs. `modelSelection()` validates only the original selector context; it does not turn display names, model families or an overview entry into endpoint identifiers.

`schema.ts` conservatively validates references, enums/constants, unions, nested objects, arrays and numeric/string limits without coercion or inserting defaults. The executable subset closes undeclared fields, bounds depth/size and refuses untyped Any/open maps, unsupported formats/keywords and external refs. Callers select a catalog operation, never a URL/method/raw HTTP envelope. Extra root fields, header injection, secrets, remote input/callback URLs, unsafe path segments and unknown parameters are refused. Rejected variants remain unavailable under each row's source-bound parameter policy. This deliberately restricts parts of the vendor schema; it does not claim those vendor parameters are invalid.

The approved implementation scope permits authorized GET metadata/content reads and the explicitly enumerated synchronous generation families. All voice-family mutations are denied, including design, preview, settings, samples, creation and cloning. Other administrative/project/agent/training mutations remain catalogued behind the separate owner-authorization and exact-lifecycle limitation. No generic request executor bypasses that policy. WebSockets/reverse listeners remain unavailable. Structured event/timestamp streams need a protocol-specific decoder; raw audio streams require an explicit terminal receipt and bounded nonempty bytes. HTTP failure/timeout/truncation after entry is Unknown, never retried. Timestamp JSON remains a bounded JSON artifact; no playable-media decoding is claimed.

The ports are consumer contracts, **not SDK method declarations or delivered host wiring**. They intentionally have no fallback network, shell, global bucket, timer or secret-value API. `access` and `permitted` must obtain fresh host policy, account entitlement and owner/workspace/actor/run/input grants. Human approval must come from exact host policy, never merely `actor.kind=local` or UI args. Every input ID must bind immutable size/SHA identity in the trusted host grant, revalidated at final entry; a mutable path or expired selected-file grant is insufficient. The shared request binding includes operation revision, exact parameters and input references. These port obligations require actual host proof in HIG-11.

The pure wire descriptor pins `https://api.elevenlabs.io`, refuses redirects/retries, names only the plugin-scoped `elevenlabs-api-key` reference and bounds bytes/time. The host must check its current network grant and credential-origin pin before secret resolution and keep credential values/reflections out of returned data/errors. No key is read here. JSON responses are schema-validated, bounded to at most 256KiB **UTF8 bytes**, then sanitized before persistence. Oversized transcripts/timestamps refuse without truncation. Multipart has at most 16 scalar text/file-marker parts, with authorized opaque input references; nested JSON fields and repeated fields remain unavailable until their exact documented serialization is implemented. No JSON-MIME multipart part is invented. The injected file/output store must provide confined regular-file/MIME/identity validation; fixture byte arrays are not live media-confinement proof.

`enter()` and `receipt()` are backend-only seams for a future reviewed explicit-marker host wrapper, never exposed to untrusted UI/agent args. Receipt completion requires the original bound request and continuation epoch. Transport IDs are never provider IDs. The synchronous fixture driver `start()` performs at most one transport entry. A returned host marker must retain the action/continuation durably; suppressed continuation, cancellation or reload preserves Unknown and cannot replay payment. These synchronous methods never return arbitrary Promises. No guessed `host.transfer`/view context/scheduler integration is installed.
