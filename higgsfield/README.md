# Higgsfield

Candidate package inputs, version **0.1.0**. This is not an installable or released Studio. Production default wiring, generated logic/UI output and combined acceptance belong to **HIG-11 / task_3xiri2**. `minCodeterm: 1.18.0` is a candidate target, not evidence that a released or installed host/SDK implements the required contracts.

The accepted source prepares Higgsfield image/video requests and exposes a Studio UI over the shared `media-shared` foundation. Native model audio controls remain model-specific; there is no sourced standalone Higgsfield speech/music endpoint. The dated inventory covers 92 catalog entries and 13 shared operations, including explicit unavailable schemas, account restrictions and transport/runtime limitations. Discovery is not executable whole-API proof.

Start with [the agent guide](guide.md), [command source contracts](COMMANDS.md), [service evidence](SERVICE.md), [UI evidence](UI.md), [research](RESEARCH.md) and [platform gaps](PLATFORM-GAPS.md). [RELEASE-EVIDENCE.md](RELEASE-EVIDENCE.md) records preparation status and every pending final gate.

The candidate manifest requests only the API host `api.higgsfield.ai`, its own secret bucket, agent command routing and host surfaces. It declares the reviewed source surface, finite media types and gesture actions. Real output/upload hosts are unknown and are not wildcarded. Binary transport, input production, durable scheduling, trusted document/result authorization and typed Blueprint registration remain incomplete; the manifest does not turn those missing implementations into capabilities. No subprocess, arbitrary filesystem, webhook ingress or agent-spawn grant is added.

Authentication uses the full `KEY_ID:KEY_SECRET` pair named `higgsfield-api-key` in the Higgsfield plugin bucket. A global item with the same name does not prove plugin scope. This preparation never reads, copies, provisions or replaces any credential. Do not put credentials in prompts, argv, source, logs, screenshots or evidence. HIG-11 must resolve scope using approved secret procedures without disclosure.

Preparation and examples cost $0. Preparing, inspecting or reusing an intent does not authorize submission. Paid proof needs Watt's explicit purpose/parameters, authoritative cost basis, atomic maximum and per-vendor/aggregate ledger approval. Missing/stale/unknown pricing waits; uncertain submission must never automatically replay. Existing voices/settings and selected transcription backend stay untouched.

Each official plugin owns its version independently. The marketplace reads this separate repository's default `main`; a lane commit is not publication. Follow the [repository release procedure](../README.md#releasing-a-plugin) only after HIG-11's final evidence and Elgar's release decision. No app release/tag workflow applies here.
