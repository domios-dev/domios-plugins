## Ownership and transport

It supplies composer/feed shell, schema fields, price, activity, grouped history and inspector structure. Higgsfield's `ui/src/App.tsx` supplies vendor tiles and media-specific inspector. The pure HIG-6 foundation in `media-shared/src` is unchanged. HIG-10 must consume these components rather than copy the shell or write common files. Common receives adapter text/units and slots; it contains no vendor/model/endpoint branching.

`src/ui.ts` supplies document-only `ui.snapshot({offset?,limit?})`, `ui.details({id})` and `ui.schema({operation})`. All resolve current access through the same CommandPorts resolver and same service history/catalog. A host-registered document/frame/surface is required; object-shaped forged context is not authority. Snapshot pages are 1–48 items, offset 0–10,000; private details are bounded to 128 KiB and schemas are actual catalog field/constraint objects. Unknown argument keys and unowned IDs refuse. Public agent verbs and summaries are unchanged. Private prompts/settings go only to the authorized document; activity excludes them. Scope/binding/authRevision/approval, transport URLs, raw errors and host file paths do not enter DTOs.

The real entry is `ui/src/main.tsx`: `ct.invoke` plus `ct.onSurfaceStateChanged` through a typed injection seam. No interval derives job lifecycle; refresh follows invalidation or an explicit completed action. Missing bridge/admission/quote/media ports remain unavailable. Note (optional), under the collapsed Note section, is bounded local draft text, **not audit or host approval evidence**. Trusted proof/admission must supply its own current authority; merely showing a button grants none. Provider/service cost and noReplay algorithms are unchanged. The catalog disables missing-price/support rows. An injected quoteSupported predicate may advertise other safely supported estimators; without one, only the documented Soul 2 estimator is offered and still requires an actual quote port.

`ui/src/media.ts` is a typed injection adapter, not released SDK wiring. It accepts only approved passive image/audio/video MIME plus a host-validated exact-frame URL, keeps handles transient, remints on reopen, caps TTL, and invokes save only through the button gesture. Expiry produces the foundation's free-reopen copy. Production does not construct a fake adapter or use local fixtures. Live Courier/CSP/gesture/frame/availability proof stays HIG-11. The source feed has metadata placeholders until an approved actual feed-image acquisition path is wired; no remote image URL or GIF autoplay is fabricated.
