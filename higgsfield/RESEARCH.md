## Shared transport, lifetime and ownership

Authentication is `Authorization: Key KEY_ID:KEY_SECRET`; the full pair belongs under `higgsfield-api-key` in the plugin host-secret bucket. Legacy `hf-api-key`/`hf-secret` exist, but are not the chosen new-integration contract. Account credentials scope requests/references and billing to a personal account or organization. Admin-only key/webhook/SSO/billing mutations are Console controls; this research does not claim an ordinary model API for them. [Authentication](https://docs.higgsfield.ai/docs/authentication.md), [roles](https://docs.higgsfield.ai/docs/enterprise/organizations.md), [access control](https://docs.higgsfield.ai/docs/enterprise/access-control.md).

Generation returns immediately with `request_id`, `status_url`, `cancel_url`; use validated returned URLs with same-account auth. Preserve exactly **queued, in_progress, completed, failed, nsfw, canceled**. Only a request whose **every job is queued** can be canceled; successful cancellation is202 with empty body, started work400. `deleted` is a deletion receipt, not a seventh generation state. Training instead returns reference `id` and has **not_ready, queued, in_progress, completed, failed**; training cancellation/retention are not established. [Requests](https://docs.higgsfield.ai/docs/concepts/requests.md), [training](https://docs.higgsfield.ai/docs/models/soul-id/create-character.md).

`Idempotency-Key` binds one generation intent in an account across key rotation, with unchanged endpoint, JSON including omitted/null/array order, webhook and retention header; mismatch422 must not create a fresh key automatically. Replay receipt can say queued after completion; reconcile current status. Provider recovery documentation does **not** authorize this plugin to automatically retry an uncertain submission. Persist a local unknown state and reconcile through an explicitly authorized safe path. Uploads, estimates and training lack established generation replay protection. [Idempotency](https://docs.higgsfield.ai/docs/concepts/idempotency.md).

Polling/terminal webhooks are documented, not live media streaming, intermediate previews, percentages or ETAs. The SDK method named subscribe polls; do not advertise native generation streams. Webhooks require public HTTPS, raw-body Standard Webhooks HMAC/timestamp verification, durable dedupe, ≤10s response; network/5xx retry up to2h,4xx permanent, polling fallback. A signing secret is created only on Console reveal; this was not done. Current host `webhookReceiver` is not generic Higgsfield ingress. [Polling](https://docs.higgsfield.ai/docs/concepts/polling.md), [webhooks](https://docs.higgsfield.ai/docs/how-to/webhooks.md).

Files expire seven days after terminal state; `Hf-Expires-After`3600..account retention only shortens it. `expires_at` is authoritative output expiry. Explicit finished-request deletion or shorter retention also removes prompt/params; default seven-day file expiry retains prompt/params. Billing records remain. Uploaded/prepared reusable inputs are independent and deleted within seven days; third-party provider policies apply. Trained reference retention is unknown. A free reopen/reacquire of a saved file is distinct from vendor-file loss. [Retention](https://docs.higgsfield.ai/docs/enterprise/data-retention.md).

Upload preparation takes a supported MIME and returns one-hour `upload_url`, `public_url` and exact `upload_headers`. PUT bytes with those headers, never the Higgsfield auth pair to storage. Model-specific media sizes/durations remain in each schema/notes. Exact real output/upload host allowlists are **unknown**; illustrative `example.com`/example CDNs are not allowlist proof. Metadata fetch is text-only in the inspected SDK; lossless binary download/upload and bounded local delivery remain external prerequisites. [Uploads](https://docs.higgsfield.ai/docs/concepts/file-uploads.md).

Concurrency and queue limits depend on account/model. Extra work queues; full queue429 returns Retry-After and no created/charged request. Batch outputs count individually. Account capacity in the dashboard is authoritative; no account was inspected. Public price-page deposit tiers are marketing/account rules, not permission to deposit or run paid proofs. [Rate limits](https://docs.higgsfield.ai/docs/concepts/rate-limits.md).
